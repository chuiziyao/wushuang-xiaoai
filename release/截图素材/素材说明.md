## 使用建议
- 风险段（口播第 5 段）建议配 **01 登录页** 或单独做一张红黄警告字幕卡，停留 3 秒以上。
- 可补充实拍素材：小爱音箱实物、对着音箱说话、音箱出声播放（手机拍即可）。
- GitHub 仓库页建议**自行屏幕录制**滚动展示（仓库地址见口播收尾），更有真实感。
- 全片基调低调：个人折腾分享，反复强调"研究用途 / 小号 / 24h 删除 / 支持正版"。
