# 无双小爱同学 · 安装使用说明（分发包 v20261120）

> 让小爱音箱接入大模型对话（豆包）+ 自由播放本地/网易云音乐，跑在你的群晖 NAS 上。

---

## ⚠️ 重要风险提示（务必先读）

**本工具仅供个人学习与研究测试，请勿用于商用或对外提供服务。**

- 大模型对话、网易云音乐等功能通过**模拟网页登录态调用非官方接口**实现，
  这类做法**违反平台服务条款**，**可能触发风控、限制登录甚至封号**。
- **强烈建议使用小号**（非主力账号）登录豆包/网易云/小米，**一切后果自行承担**。
- 逆向接口**不稳定**：平台改版后可能失效，登录态会过期，需重新扫码/提取。
- 本项目不分发任何账号、不收集任何数据；所有凭证仅保存在你自己的 NAS 上。
- 下载后 24 小时内请于测试完成后自行删除相关接口调用，支持官方正版服务。

**继续安装即表示你已理解并自愿承担上述风险。**

## 一、准备工作

| 需要 | 说明 |
|---|---|
| 群晖 NAS | DSM 7.x，已安装 **Container Manager**（套件中心可装） |
| 小爱音箱 | 已用米家 APP 绑定到小米账号（本工具支持小爱音箱 Pro 等主流型号） |
| 小米账号 | **建议小号**，音箱绑定的那个账号 |
| 豆包账号 | **建议小号**，浏览器登录 doubao.com |
| 网易云账号 | 可选，用于同步歌单（**建议小号**） |
| 电脑浏览器 | Edge 或 Chrome（装 Cookie 助手扩展用） |

音乐文件：把 mp3/flac 放进 NAS 的共享文件夹（如 `Music`），本工具会扫描入库。

## 二、安装方式 A：群晖 SPK 套件（推荐，全程图形界面，无需 SSH）

1. **下载套件**：本分发包 `群晖SPK套件/wushuang_xiaoai-0.1.0-0001.spk`。
2. **打开套件中心** → 右上角「**手动安装**」→ 选择该 `.spk` 文件 → 下一步。
3. 安装向导中：
   - 设置**管理后台密码**（务必记住，登录后台用）。
   - 填写 **NAS 局域网地址**，形如 `http://192.168.1.10:8080`
     （把 IP 换成你 NAS 的实际局域网 IP；**不要填 127.0.0.1**）。
   - 指定**音乐目录**（如 `/volume1/Music`）。
4. 完成安装。首次启动会自动构建容器镜像（**约 3–10 分钟**，视网速而定，请耐心等待）。
5. 安装完成后，DSM 桌面会出现「**无双小爱同学**」图标，点击直达后台；
   或浏览器访问 `http://你的NAS_IP:8080`。

> 若首次安装后图标打不开或容器未起：在 Container Manager →「项目」里找到
> `wushuang-xiaoai`，点「启动」即可；仍异常时见第六节排查。

**升级**：套件中心手动安装新版 SPK 即可，配置与数据自动保留。
**卸载**：套件中心卸载；如需彻底清除数据，再删除
`/var/packages/wushuang_xiaoai/etc` 与 `var` 目录。

## 三、安装方式 B：Docker（适合有 docker compose 经验的用户）

> 此方式需要会用命令行运行 docker compose，普通群晖用户请用方式 A。

1. 解压 `Docker版/` 到任意目录。
2. 复制 `.env.example` 为 `.env`，修改：
   ```
   WUSHUANG_PUBLIC_URL=http://你的NAS_IP:8080
   WUSHUANG_ADMIN_PASSWORD=设一个强密码
   MUSIC_DIR=/volume1/Music
   ```
3. 构建并启动：
   ```
   docker compose up -d --build
   ```
4. 浏览器访问 `http://你的NAS_IP:8080`。

`Docker版/` 已含网易云协议组件源码（`reference/ncm-api-enhanced`），可离线构建。

## 四、安装浏览器扩展（提取豆包登录凭证）

1. 解压 `浏览器插件/cookie-helper/` 到电脑任意文件夹。
2. Edge 地址栏输入 `edge://extensions`（Chrome 为 `chrome://extensions`）回车。
3. 打开「**开发人员模式**」开关。
4. 点「**加载解压缩的扩展**」→ 选择 `cookie-helper` 文件夹。
5. 工具栏出现「无双Cookie助手」图标。

> 扩展仅在你本机浏览器运行，**不上传任何数据**。千问/元宝按钮已置灰
> （2026 年协议变更，暂不可用），当前仅支持豆包。

## 五、后台配置（按顺序）

登录后台 `http://你的NAS_IP:8080`（密码为安装时设置的那个）。

### 1. 小米账号（必须）
「账号」页 → 绿色「**📱 米家扫码登录**」→ 用**米家 APP**（登录音箱绑定的小米账号）扫码确认。
登录后自动发现音箱。

### 2. 启用音箱
「设备」页 → 找到你的音箱（如「小爱音箱Pro」）→ 打开「**启用**」开关。

### 3. 豆包大模型（对话功能）
1. 电脑浏览器登录 doubao.com，随便发句话确认能用。
2. 点「无双Cookie助手」扩展 → 豆包「**提取 sessionid**」→「**复制**」。
3. 后台「账号」→「添加服务商」→ 预设选「**豆包网页版（免费·内置免签名）**」
   → Key 框粘贴 → 保存 → 点「**测试**」，显示成功即可。

### 4. 网易云音乐（可选）
「账号」页网易云区 →「**获取登录二维码**」→ 用**网易云音乐 APP** 扫码。
登录后「音乐」页 → 添加歌单（填网易云歌单 ID）→ 同步到本地。可设每天自动同步。

## 六、开始使用（对音箱说）

| 说法 | 效果 |
|---|---|
| "小爱同学，**请帮我**用一句话介绍长城" | 豆包大模型回答（小爱可能先抢答一句，稍等听第二个答案） |
| "小爱同学，播放歌单 我喜欢的音乐" | 播放同步的网易云歌单 |
| "小爱同学，播放歌曲 晴天" | 播放本地曲库歌曲 |
| "下一首 / 暂停播放 / 音量大一点 / 随机播放" | 播放控制 |

> 「请帮我」是默认触发词，可在「设备」页自定义。闹钟、米家控制等小爱原生功能不受影响。

## 七、常见问题

- **图标打不开 / 网页打不开**：确认容器在运行（Container Manager → 项目 → 启动）；
  确认访问的是 `http://NAS_IP:8080`（http 不是 https）；防火墙放行 8080 端口。
- **音箱没反应**：确认设备已「启用」、小米登录态正常（账号页显示 ok）；
  触发词要说对（默认"请帮我"）。
- **豆包测试失败 / 回答"登录态失效"**：sessionid 过期，重新用扩展提取粘贴。
  若提示风控（710022004），等约 30 分钟或换网络，**切勿频繁重试**。
- **小米掉线**：账号页重新米家扫码。
- **网易云同步失败**：重新扫码登录；部分歌曲版权受限无法下载属正常。
- **首次启动很慢**：构建镜像需下载依赖，3–10 分钟正常，请勿反复重启。
