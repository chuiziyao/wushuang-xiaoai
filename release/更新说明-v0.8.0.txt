🖥️ 重磅：电脑桌面版来了（Windows 免安装便携包）
📦 解压到任意文件夹双击即用，无需安装 Python、无需 Docker、无需 NAS
🧯 采用目录版（onedir），不向系统 TEMP 解压，规避"Could not create temporary directory!"错误
🚫 电脑端不用登录任何音乐软件（网易云/酷狗/QQ/汽水都不需要）
📂 指定一个本地文件夹，歌曲和视频扫描后直接推给小爱音箱
🎬 视频支持 mp4/mkv/mov/webm 等（带屏小爱可显示画面，无屏机型尽力而为）
📡 新增「在线音源」页：网络电台/播客/有声书直链，音箱直接拉流，直播不切歌
🧠 大模型对话与 Docker 版完全一致：豆包网页版免费内置 + 官方 API 多服务商降级
📱 米家扫码、多音箱管理、播放控制、语音口令、双状态切换全部保留

🏗️ 架构升级：一套代码多平台
🪟 Windows：便携 zip（PyInstaller + WebView2 原生窗口，自动兜底浏览器+托盘）；可选 Inno Setup 安装版
🍎 macOS：同一脚本构建 .app（WKWebView）

📌 桌面版上手 5 步
1️⃣ 解压 zip 到任意可写文件夹，双击其中的 exe（SmartScreen 点"更多信息→仍要运行"；防火墙勾选"专用网络"允许）
2️⃣ 登录后台（初始密码 wushuang，请到设置修改）→ 账号页米家扫码 → 设备页启用音箱
3️⃣ 账号页配置大模型（豆包 Cookie 用浏览器扩展一键提取，或填官方 API Key）
4️⃣ 歌曲/视频放进媒体目录（默认"音乐\WushuangXiaoai"，设置页可改）→ 音乐页扫描
5️⃣ 对音箱说"小爱同学，请帮我……"或"播放歌曲 XXX"

💡 数据/媒体默认在程序文件夹内（data/media），整个文件夹可拷贝迁移；设置页可改目录/端口/拉流地址
💡 重复双击不会多开；窗口关闭即退出服务
