# 桌面版使用说明（Windows / macOS / Linux）

> 作者：**锤无双** · 技术交流QQ群：**170621740** ·
> [📺 教程视频（B站）](https://www.bilibili.com/video/BV1RFyozyE8v/)

桌面版与 Docker 版共用同一套代码与后台界面，**大模型对话、米家扫码、设备管理、
播放控制、语音指令完全一致**；差异只有两点：

1. **不登录任何音乐软件**（无网易云/酷狗/QQ/汽水账号与同步）；
2. 曲库 = **本地文件夹的歌曲与视频** + **在线音源直链**。

## 一、Windows（免安装便携版）

> v0.8.0 起改为**目录版（onedir）便携包**，不再用单文件 onefile。
> 原因：单文件版每次启动都要向系统 TEMP 解压，部分安全软件/受限环境会拦截，
> 弹「**Could not create temporary directory!**」。目录版**不解压**、数据存程序目录内，
> 彻底规避该问题，启动也更快。

### 安装运行

1. 下载 `无双小爱同学-桌面版-v*-Windows.zip`，**解压到任意可写文件夹**
   （如 `D:\无双小爱同学` 或桌面，**不要**直接在压缩包里双击）。
2. 进入解压出的文件夹，双击 `无双小爱同学.exe`。
   首次可能弹出 **SmartScreen 提示**（开源工具未购买代码签名证书）：
   点「**更多信息**」→「**仍要运行**」。
3. 首次运行 **Windows 防火墙**弹窗：勾选「**专用网络**」并允许——
   音箱要通过局域网 HTTP 从本机拉流，拒绝则无法播放。
4. 程序打开**内置浏览器窗口**（Windows 用 WebView2，与系统 Edge 是否提权无关，
   不会弹"现有实例以提升的权限运行"之类的系统浏览器对话框）。
   **程序全程不主动调用系统浏览器**，页脚教程等外部链接也在内置窗口内打开。
   **再次双击**程序会把已有内置窗口恢复并置前（不会多开）；
   关闭内置窗口即退出服务，也可在「设置」页点「**退出桌面服务**」。
   若内置窗口确实不可用（如缺 WebView2 运行时），程序仅弹窗告知管理地址，
   由你自行复制链接打开，服务不受影响。

> 想要「安装版」？可用 `scripts/desktop-installer.iss`（Inno Setup）把目录打成
> 安装程序，装到 Program Files；此时数据自动回退到 `%LOCALAPPDATA%\WushuangXiaoai`。
> 多数情况便携版更省事，无需安装。

### 首次配置

1. 登录管理后台：初始密码 `wushuang`，登录后到「设置」页修改。
2. 「账号」页 → **米家扫码登录**（用音箱绑定的小米账号扫码）。
   ⏰ **小米登录态有有效期，预计每 1–2 天就要重新扫码一次**；界面显示"登录失效"
   或播放页红条提示时，到「账号」页重新米家扫码即可恢复。
3. 「设备」页 → 启用你的音箱。
4. 「账号」页 → 配置大模型服务商（与 Docker 版一致）：
   - **豆包网页版**（免费）：用 `tools/cookie-helper` 浏览器扩展一键提取 Cookie；
   - 或**官方 API**：火山方舟 / 阿里百炼 / DeepSeek / 任意 OpenAI 兼容端点。
5. 对音箱说「小爱同学，请帮我……」或「变身」进入无双模式试试。

### 听歌

- **本地歌曲/视频**：把文件放进媒体目录（默认 `<程序文件夹>\media`，
  「设置」页可改到任意文件夹），「音乐」页点「扫描曲库」，
  然后语音「播放歌曲 XXX」或在「曲库/播放」页点歌。
  - 视频（mp4/mkv/mov/webm 等）会尽力推送：**带屏小爱**（触屏音箱系列）可显示画面，
    无屏机型能否出声取决于固件，属尽力而为。
- **在线音源**：「在线音源」页添加网络电台/播客/有声书的 http(s) 音频直链，
  音箱直接从音源拉流。直播类（时长填 0）不会超时切歌。
  语音「播放歌单 在线音源」可顺序播放全部音源。

### 数据位置

便携版默认把一切放在**程序文件夹内**（自包含，可整个文件夹拷贝迁移）：

| 内容 | 位置 |
|---|---|
| 数据库/密钥/日志/配置 | `<程序文件夹>\data` |
| 媒体目录（默认） | `<程序文件夹>\media`（可在设置页改到任意目录） |
| 日志 | `<程序文件夹>\data\logs\desktop.log` |

若程序装在只读位置（如 Program Files 安装版），数据自动回退到
`%LOCALAPPDATA%\WushuangXiaoai`。源码运行（非打包）时默认用 `%APPDATA%\WushuangXiaoai`。

「设置」页可修改媒体目录/端口/音箱拉流地址（多网卡时），点「保存并重启」生效。
重复双击 exe 不会多开：已有实例时直接打开其管理页面。

## 二、macOS / Linux

同一代码库构建（PyInstaller 不支持交叉编译，需在对应系统上执行）：

```bash
pip install -e ".[build]"
python scripts/build_desktop.py
```

- **macOS**：产物为 `.app`（WKWebView 原生窗口）。未签名应用首次打开：
  右键 → 打开，或「系统设置 → 隐私与安全性」允许。
- **Linux**：原生窗口依赖 WebKitGTK：
  `sudo apt install gir1.2-webkit2-4.1 gir1.2-gtk-3.0`；
  无图形环境可加 `--browser`：不创建窗口，服务常驻，地址见日志/弹窗，自行打开管理。
- CI：推送 `v*` tag 后 `.github/workflows/desktop.yml` 自动构建四平台产物并发布 Release。

## 三、鸿蒙手机/平板当遥控器

- **HarmonyOS NEXT / 5.x**：用 DevEco Studio 打开 `harmony/` 工程构建 HAP
  （详见 [harmony/README.md](../harmony/README.md)），填入电脑局域网地址即可遥控。
- **HarmonyOS 4.x 及以下**：直接安装分发包里的 `无双遥控器-v*.apk`。

## 四、常见问题

| 现象 | 处理 |
|---|---|
| **Could not create temporary directory!** | 这是旧版单文件 onefile 的问题；请改用 v0.8.0+ 的**目录版便携包**（不解压，已规避）。若仍用旧单文件版，把系统 TEMP/TMP 指到可写目录或临时关闭拦截解压的安全软件 |
| SmartScreen 拦截 | 更多信息 → 仍要运行（未签名开源工具的正常现象） |
| 音箱不出声/播放失败 | 防火墙允许专用网络；「设置」页确认「音箱拉流基地址」是音箱可达的局域网 IP；小米**登录失效**（约 1–2 天一次）时到「账号」页重新扫码 |
| 高解析无损（192kHz/24bit WAV/FLAC）播放卡顿/断续/没声 | LX06/S12A 等老音箱扛不住高码率。到「设置」页开启「高解析无损自动转码」，服务端会转成音箱能稳播的 MP3。**桌面版需自备 ffmpeg**：把 ffmpeg.exe 放到程序目录或 PATH，否则该开关自动跳过（Docker/SPK 已内置） |
| 窗口打不开/白屏 | v0.8.1+ 只用内置 WebView2 窗口，不调用系统浏览器。若弹窗提示内置窗口失败，按提示安装 [WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/)；也可复制弹窗中的地址自行打开 |
| 日志报 `Failed to resolve Python.Runtime.Loader.Initialize`（0x80131515） | .NET Framework 把程序所在盘（如 D:）或下载解压文件判为"网络位置"拒绝加载程序集。v0.8.1+ 随包附带 `无双小爱同学.exe.config` 已根治（运行时也会自动补写）；请确认 exe 旁有该文件，或升级到新便携包 |
| 第二次双击"没反应" | 服务已在后台运行（单实例）。新版会把内置窗口恢复并置前；若窗口被最小化到托盘，点托盘「打开管理后台」 |
| Edge 提示"现有实例以提升的权限运行" | 旧版会把地址递送给系统 Edge 所致；v0.8.1+ 全程内置窗口，不再触发该对话框 |
| 如何彻底退出 | 关闭内置窗口；或「设置」页点「退出桌面服务」；或任务管理器结束 `无双小爱同学.exe` |
| 端口被占用 | 程序自动尝试 8080–8090；也可在「设置」页改端口 |
| 视频无法播放 | 无屏机型固件限制；建议优先音频文件，或换带屏小爱 |
| 在线音源失效 | 部分平台直链带时效签名，过期需重新获取地址 |

## 风险与合规

与 Docker 版相同：仅供个人研究测试，调用非官方接口存在风控/封号风险，
建议小号，后果自负；音乐内容版权归原作者所有。服务只应暴露于局域网，
管理密码务必修改，不要将端口映射到公网。
